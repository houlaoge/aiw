根据指令自动搭建：网站首页、栏目页，每日定时生成文章内容页等

- 纯静态建站，搜索引擎友好
- 自动提交搜索引擎
- 谷歌、必应均可7天收录，百度4周收录

## 🚀 一键安装

登录Linux服务器（最低配：2核4G）执行下面的指令，不要安装宝塔、nginx、apache等其他占用80端口的软件

```bash
curl -SsL v.gd/aiw_ins | bash
```
[在线SSH工具](https://ssh.houlaoge.workers.dev/)

## ✨ 特性

### AI自动生成网站
- 支持全球所有语种
- 网站标题、首页、栏目页、文章页均可设置独立指令
- 批量管理、插入JS代码
- 站点互连、轮连
- 自动生成或自定义LOGO

### SEO管理
- 自动提交必应
- 每日定时推送必应
- 收录排名

### 流量统计
- 访客明细
- 自动记录蜘蛛
